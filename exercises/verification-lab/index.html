How many kits
does a workshop need?

A local exercise in checking an agent's work. No account, upload or connection needed.

Deliberately unfinished: this practice app contains one calculation defect. Predict a result before you try it. Do not use it for real ordering.

The requirement

Each participant needs one kit. Kits come in sealed packs of four. Buy enough whole packs for everyone, with as few spare kits as possible. With zero participants, buy zero packs.

Enter a whole number from 0 to 1000. These limits are part of this exercise.

Predict the answer, then calculate.

You are the reviewer

  1. Write a prediction using the requirement.
  2. Try a count that is not a multiple of four.
  3. Explain any difference before asking an agent for a fix.
  4. After a fix, repeat both the failing example and one earlier working example.

The agent's handover says: “I tried eight participants and got two packs. Ready for every workshop.” Decide what that evidence actually proves.
